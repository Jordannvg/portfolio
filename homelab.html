Accueil / Homelab maison.lan

Mon Infrastructure Homelab

Environnement personnel physique et virtualisé sous Proxmox VE, hébergeant une VM Debian, des conteneurs Docker et des services bare metal sous le domaine local maison.lan.

Architecture Serveur

Découpage Hôte, VM & Services

Actif en local (24/7)
Couche 1 • Hôte Physique

Proxmox VE

Hyperviseur bare metal de type 1. Gestion des ressources matérielles (CPU, mémoire vive, stockage ZFS/ext4) et des interfaces de pont virtuel réseau (vmbr0).

Hôte KVM
Couche 2 • Machine Virtuelle

VM Debian 12

Système d'exploitation Linux socle. Héberge le démon Docker pour les microservices et fait tourner Nextcloud en direct sur le système.

Debian GNU/Linux
Couche 3 • Bare Metal

Nextcloud

Installé en natif sur la VM Debian. Optimisé avec PHP-FPM pour l'exécution rapide des scripts et un cache mémoire Redis pour le verrouillage des transactions.

cloud.maison.lan

Services Conteneurisés Docker

Conteneurs actifs orchestrés sur la machine virtuelle Debian :

Contrôle

Dockhand

Interface de supervision pour surveiller l'état, l'utilisation mémoire et les logs des conteneurs en cours d'exécution.

Sécurité

Vaultwarden

Gestionnaire de mots de passe auto-hébergé avec chiffrement de bout en bout et synchronisation multi-appareils.

vault.maison.lan
Base de données

Postgresql

Base de données relationnelle assurant la persistance des données pour les applications de l'infrastructure.

Réseau & SSL

Nginx Proxy Manager

Reverse proxy qui redirige les requêtes des sous-domaines vers les conteneurs appropriés avec terminaison SSL/TLS.

npm.maison.lan
Résolution DNS

Technitium DNS

Serveur DNS récursif et autoritaire pour la zone locale maison.lan avec filtrage des traceurs publicitaires.

dns.maison.lan
Médias

Jellyfin

Serveur de streaming multimédia personnel sans télémétrie ni dépendance cloud externe.

media.maison.lan
Audio

Navidrome

Serveur de streaming musical personnel, léger et compatible avec les applications clientes Subsonic.

music.maison.lan
Outil de Veille

FreshRSS

Agrégateur de flux RSS auto-hébergé, servant directement d'outil quotidien pour ma veille technologique BTS SIO.

rss.maison.lan
